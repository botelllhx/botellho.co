Anexe os gifs aqui com exatamente estes nomes. Enquanto o arquivo não existir, o
hover da linha correspondente simplesmente não mostra nada (sem quebrar layout).

| linha na home                    | arquivo esperado         |
| -------------------------------- | ------------------------ |
| sem lorem ipsum                  | `lorem.gif`              |
| sem tema pronto                  | `tema.gif`               |
| sem powerpoint                   | `powerpoint.gif`         |
| sem reunião que era e-mail       | `reuniao.gif`            |
| sem site travado                 | `travado.gif`            |
| sem preguiça                     | `preguica.gif`           |

Formato: gif quadrado (ou perto disso) fica melhor, o container recorta em ~288px.
Se quiser trocar as frases ou adicionar linhas, é em `src/system/GifList.tsx`.
